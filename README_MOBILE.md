# 🍺 Beerpedia — установка на Android

Полная инструкция по запуску проекта локально на Android-телефоне через Termux.

---

## 📋 Что нужно

- Android 7.0+
- ~600 МБ свободного места (код + данные)
- Приложение **Termux** (качать из [F-Droid](https://f-droid.org/en/packages/com.termux/), не из Play Market)

---

## 🚀 Быстрый старт (рекомендуется)

Откройте Termux и вставьте одну команду:

```bash
pkg install curl -y && curl -fsSL https://raw.githubusercontent.com/babahsanya/beer/main/setup.sh | bash
```

Скрипт сам:
1. Установит Python, Git, OpenSSL
2. Склонирует проект в `~/beerpedia`
3. Создаст виртуальное окружение и поставит зависимости
4. Создаст ярлык запуска

После установки запустите:

```bash
beerpedia
```

И откройте в браузере телефона:

```
http://127.0.0.1:8000
```

## 📦 Шаг 2: Добавить данные (важно!)

⚠️ **Важно:** в Git НЕ входят база данных и картинки (~500 МБ). Без них проект запустится, но будет пустой. Картинки не обязательны (покажет эмодзи 🍺), но база нужна.

### Способ 1: Автоматически с GitHub Release (рекомендуется) ⭐

`setup.sh` сам предложит это сделать. Если пропустили — вручную:

```bash
cd ~/beerpedia
bash fetch_data.sh
```

Скрипт скачает `beerpedia_data.zip` (~250 МБ) с GitHub и распакует. Нужен Wi-Fi и ~10 минут.

> ⚠️ Этот способ работает, **только если вы опубликовали релиз**. Если скрипт пишет «релиз не найден», используйте Способ 2.

### Способ 2: Перенос вручную с ПК

**На ПК** (в папке проекта):

```bash
bash pack_data.sh
```

Создаст `beerpedia_data.zip` (~250 МБ после сжатия).

**Как перенести архив на телефон:**

#### 2a. По Wi-Fi (рекомендуется для 500 МБ)

На ПК:
```bash
python -m http.server 8000
```
Узнайте IP ПК: `ipconfig` → `192.168.1.100`

На телефоне (в Termux):
```bash
cd ~/beerpedia
pkg install unzip -y
curl -O http://192.168.1.100:8000/beerpedia_data.zip
unzip beerpedia_data.zip
rm beerpedia_data.zip
```

#### 2b. Через Telegram/облако

1. На ПК запустите `bash pack_data.sh` → получите `beerpedia_data.zip`
2. Отправьте архив себе в Telegram / загрузите в облако
3. На телефоне скачайте в загрузки
4. В Termux:

```bash
cd ~/beerpedia
pkg install unzip -y
cp /sdcard/Download/beerpedia_data.zip .
unzip beerpedia_data.zip
rm beerpedia_data.zip
```

#### Способ 3: Только базу (без картинок, ~47 МБ)

Если не нужны фото пива, перенесите только `beer_database.db` любым способом, и положите в `~/beerpedia/`.

## 🚀 Для владельца ПК: как опубликовать данные в релиз

Чтобы Способ 1 работал, нужно один раз опубликовать данные в GitHub Release.

**На ПК** (где есть полная база и картинки):

```bash
bash publish_release.sh
```

Скрипт:
1. Упакует `beerpedia_data.zip` (база + картинки, ~250 МБ)
2. Создаст GitHub Release с тегом `data-v1`
3. Загрузит архив как asset

После этого `fetch_data.sh` на телефоне будет работать. Чтобы обновить данные — просто запустите `publish_release.sh` снова (он пересоздаст релиз).

> 📌 GitHub Releases бесплатны до 2 ГБ на файл — наш архив ~250 МБ помещается легко.

После установки данных перезапустите:

```bash
beerpedia
```

Должно появиться: `🍺 Пивная энциклопедия запускается на http://127.0.0.1:8000`

В браузере откройте `http://127.0.0.1:8000` — увидите каталог с ~7700 позициями.

## 🧪 Нет данных? Демо-база для проверки интерфейса

Если нет возможности перенести полную базу, можно создать мини-демо (5 позиций) для проверки интерфейса:

```bash
cd ~/beerpedia
bash create_demo_db.sh

```

## 🛠 Команды управления

| Команда | Что делает |
|---------|-----------|
| `beerpedia` | Запустить сервер |
| `cd ~/beerpedia && bash run.sh` | То же самое (явно) |
| `cd ~/beerpedia && git pull` | Обновить код |
| `cd ~/beerpedia && bash fetch_data.sh` | Скачать полные данные с GitHub |
| `cd ~/beerpedia && bash create_demo_db.sh` | Демо-база (5 позиций) |
| `cd ~/beerpedia && rm beer_database.db` | Удалить базу (для замены) |

## ❓ Частые проблемы

### Q: Пишет «command not found: beerpedia»
**A:** Перезапустите Termux или выполните `source ~/.bashrc`.

### Q: Сервер запускается, но страница пустая / ошибка
**A:** Нет базы данных. См. раздел «Добавить данные» выше, или создайте демо-базу.

### Q: Картинки не показываются (эмодзи 🍺 вместо фото)
**A:** Нормально. Картинки (454 МБ) не обязательны, проект работает и без них.

### Q: Порт 8000 занят
**A:** В `app.py` измените `port=8000` на другой (например, `port=8080`).

### Q: Termux убивает приложение в фоне
**A:** Termux нельзя сворачивать. Приобретите **Termux:Boot** или используйте `termux-wake-lock`:
```bash
pkg install termux-api -y
termux-wake-lock
```

### Q: Как обновить код до последней версии?
```bash
cd ~/beerpedia
git pull
```
